What this is for

Hill Weather is a free hobby project, built and run by one person. There is no company behind it and nothing is for sale.

Worth writing about: corrections, especially if the forecast said one thing and the hill said another; collaboration, if you run something the project could work with; and anything involving observations or data, which is what the site needs most.

If you would rather use your own mail client, the address is contact@hillweather.co.uk.

Please do not write about

Whether it is safe to go up a particular hill on a particular day. Nobody should be making that call from a website, and certainly not from one that has not yet been checked against real observations. Read MWIS, and in winter SAIS.
